# Apex ecosystem boundaries

Apex_ULL owns native foundations, Apex_Tick owns the bounded hardware trading-core implementation, and Apex_PerfAtlas owns evidence and deployment analysis. Finance, AI inference, graph optimization, infrastructure and governance remain independent project domains.

The native-run and Tick simulation emitters implement the Atlas v0.1 manifest shape. Host recovery, board integration, portfolio scenario, optimization and custody adapters remain candidates. Neither emitter adds the Atlas analysis runtime to a packet-processing critical path.

[Mermaid source](ecosystem.mmd) shows candidate portfolio connections. It is an intended architecture, not a diagram of a unified deployed runtime. The dated implementation descriptions in each project README govern edge status.

[AAH20 profile](https://github.com/AAH20/AAH20) retains its existing maintenance commitments and each original project thesis. Integration status advances from candidate to implemented or validated only with a concrete adapter and retained evidence.
