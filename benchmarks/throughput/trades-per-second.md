# Trades/sec Throughput Benchmark

## Overview

Measures the rate at which a system can process trade executions — from matching engine output through trade reporting, clearing, and settlement. This is the primary throughput metric for trade processing pipelines and clearing systems.

## Measurement Methodology

### What to Measure

- **Trade execution rate**: Trades generated by matching engine per second
- **Trade reporting rate**: Trades reported to exchange/clearing per second
- **Trade clearing rate**: Trades fully cleared and settled per second
- **End-to-end rate**: From match to confirmed settlement per second

### Measurement Protocol

1. **Warm-up**: 60 seconds to populate positions, accounts, and clearing state
2. **Measurement window**: 120 seconds at target trade rate
3. **Trade mix**: Realistic distribution (70% standard, 20% block, 10% complex)
4. **Repeat**: 5 iterations, report median

### Key Parameters

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Trade size | 32–128 bytes | Typical trade report payload |
| Protocol | TCP (trade reporting) | Reliable delivery required |
| Trade types | Standard, block, complex | Realistic mix |
| Clearing | Real-time + batch | Both modes measured |
| Settlement | T+0 to T+2 | Measure at each stage |

### Common Pitfalls

- **Measuring only match output**: Must measure full trade lifecycle
- **Ignoring clearing bottleneck**: Clearing can be slower than matching
- **Not testing under stress**: Trade rate spikes during market volatility
- **Ignoring position updates**: Each trade updates positions, consuming throughput
- **Not measuring reporting latency**: Delayed reporting creates backlog

## Benchmark Code

### Reference Implementation (C++)

```cpp
// trades_per_second.cpp
// Trade processing throughput benchmark

#include <atomic>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <cstring>
#include <thread>
#include <vector>
#include <memory>
#include <random>

// Trade types
enum class TradeType : uint8_t {
    STANDARD = 0,
    BLOCK = 1,
    COMPLEX = 2
};

// Compact trade structure (64 bytes)
struct alignas(64) Trade {
    uint64_t trade_id;
    uint64_t timestamp_ns;
    uint64_t symbol_id;
    int64_t price;           // fixed-point 1e-9
    uint64_t quantity;
    uint64_t buyer_order_id;
    uint64_t seller_order_id;
    uint64_t buyer_account;
    uint64_t seller_account;
    TradeType type;
    uint8_t clearing_status;  // 0=pending, 1=cleared, 2=settled
    uint16_t flags;
    uint32_t padding;
};

// Position update
struct PositionUpdate {
    uint64_t account_id;
    uint64_t symbol_id;
    int64_t net_position;
    int64_t avg_price;
    uint64_t timestamp_ns;
};

// Statistics
struct alignas(64) Stats {
    std::atomic<uint64_t> trades_generated{0};
    std::atomic<uint64_t> trades_reported{0};
    std::atomic<uint64_t> trades_cleared{0};
    std::atomic<uint64_t> trades_settled{0};
    std::atomic<uint64_t> position_updates{0};
    std::atomic<uint64_t> total_latency_ns{0};
    std::atomic<uint64_t> max_latency_ns{0};
    char pad[64 - 7 * sizeof(std::atomic<uint64_t>)];
};

static Stats g_stats;
static volatile bool g_running = false;

// Generate realistic trade
Trade generate_trade(uint64_t seq, std::mt19937_64& rng) {
    Trade trade{};
    trade.trade_id = seq;
    trade.timestamp_ns = std::chrono::high_resolution_clock::now().time_since_epoch().count();
    trade.symbol_id = 1000 + (rng() % 5000);
    trade.price = 1000000000LL + (rng() % 100000000LL);
    trade.quantity = 100 * (rng() % 1000 + 1);
    trade.buyer_order_id = seq * 2;
    trade.seller_order_id = seq * 2 + 1;
    trade.buyer_account = rng() % 10000;
    trade.seller_account = rng() % 10000;
    
    uint32_t r = rng() % 100;
    if (r < 70) trade.type = TradeType::STANDARD;
    else if (r < 90) trade.type = TradeType::BLOCK;
    else trade.type = TradeType::COMPLEX;
    
    trade.clearing_status = 0;
    trade.flags = 0;
    return trade;
}

// Simulate trade processing pipeline
void process_trade_pipeline(const Trade& trade) {
    auto start = std::chrono::high_resolution_clock::now();
    
    // Stage 1: Trade validation
    bool valid = (trade.quantity > 0 && trade.price > 0);
    
    // Stage 2: Position update (both sides)
    PositionUpdate buyer_update{trade.buyer_account, trade.symbol_id, 
                                 (int64_t)trade.quantity, trade.price, trade.timestamp_ns};
    PositionUpdate seller_update{trade.seller_account, trade.symbol_id,
                                  -(int64_t)trade.quantity, trade.price, trade.timestamp_ns};
    g_stats.position_updates += 2;
    
    // Stage 3: Trade reporting (simulated)
    bool reported = valid;
    
    // Stage 4: Clearing (simulated)
    bool cleared = reported && (trade.type != TradeType::COMPLEX || (trade.trade_id % 10) != 0);
    
    // Stage 5: Settlement (simulated)
    bool settled = cleared;
    
    auto end = std::chrono::high_resolution_clock::now();
    uint64_t latency = std::chrono::duration_cast<std::chrono::nanoseconds>(end - start).count();
    
    // Update stats
    g_stats.trades_generated++;
    if (reported) g_stats.trades_reported++;
    if (cleared) g_stats.trades_cleared++;
    if (settled) g_stats.trades_settled++;
    g_stats.total_latency_ns += latency;
    
    uint64_t prev_max = g_stats.max_latency_ns.load();
    while (latency > prev_max && !g_stats.max_latency_ns.compare_exchange_weak(prev_max, latency));
}

// Worker thread
void worker_thread(int num_trades, int thread_id) {
    std::mt19937_64 rng(thread_id * 12345);
    
    for (int i = 0; i < num_trades && g_running; i++) {
        Trade trade = generate_trade(thread_id * 1000000000ULL + i, rng);
        process_trade_pipeline(trade);
    }
}

int main(int argc, char* argv[]) {
    int num_threads = argc > 1 ? atoi(argv[1]) : 8;
    int trades_per_thread = argc > 2 ? atoi(argv[2]) : 1000000;
    
    printf("Trades/sec Benchmark\n");
    printf("Threads: %d, Trades/thread: %d\n", num_threads, trades_per_thread);
    
    g_running = true;
    
    auto start = std::chrono::high_resolution_clock::now();
    
    std::vector<std::thread> threads;
    for (int i = 0; i < num_threads; i++) {
        threads.emplace_back(worker_thread, trades_per_thread, i);
    }
    
    for (auto& t : threads) t.join();
    
    auto end = std::chrono::high_resolution_clock::now();
    double duration_sec = std::chrono::duration<double>(end - start).count();
    
    uint64_t total_trades = g_stats.trades_generated.load();
    uint64_t reported = g_stats.trades_reported.load();
    uint64_t cleared = g_stats.trades_cleared.load();
    uint64_t settled = g_stats.trades_settled.load();
    uint64_t pos_updates = g_stats.position_updates.load();
    uint64_t avg_latency = total_trades > 0 ? g_stats.total_latency_ns.load() / total_trades : 0;
    uint64_t max_latency = g_stats.max_latency_ns.load();
    
    printf("\n=== Trades/sec Benchmark Results ===\n");
    printf("Duration:           %.3f seconds\n", duration_sec);
    printf("Total trades:       %lu\n", total_trades);
    printf("Trades/sec:         %.2f M\n", total_trades / duration_sec / 1e6);
    printf("Reported:           %lu (%.1f%%)\n", reported, 100.0 * reported / total_trades);
    printf("Cleared:            %lu (%.1f%%)\n", cleared, 100.0 * cleared / total_trades);
    printf("Settled:            %lu (%.1f%%)\n", settled, 100.0 * settled / total_trades);
    printf("Position updates:   %lu\n", pos_updates);
    printf("Avg latency:        %lu ns\n", avg_latency);
    printf("Max latency:        %lu ns\n", max_latency);
    printf("Throughput/core:    %.2f K trades/s\n", total_trades / duration_sec / num_threads / 1e3);
    
    return 0;
}
```

### Python Trade Generator

```python
#!/usr/bin/env python3
"""Trade execution load generator for trades/sec benchmark."""

import socket
import struct
import time
import multiprocessing
import random
from dataclasses import dataclass

@dataclass
class Trade:
    trade_id: int
    timestamp_ns: int
    symbol_id: int
    price: int
    quantity: int
    buyer_order_id: int
    seller_order_id: int
    buyer_account: int
    seller_account: int
    trade_type: int  # 0=standard, 1=block, 2=complex
    clearing_status: int
    flags: int

def encode_trade(trade: Trade) -> bytes:
    """Encode trade to binary format (64 bytes)."""
    return struct.pack('!QQQqQQQQQBBHI',
        trade.trade_id, trade.timestamp_ns, trade.symbol_id,
        trade.price, trade.quantity, trade.buyer_order_id,
        trade.seller_order_id, trade.buyer_account, trade.seller_account,
        trade.trade_type, trade.clearing_status, trade.flags, 0)

def generate_trade_batch(batch_size: int, base_id: int) -> bytes:
    """Generate a batch of trades with realistic mix."""
    trades = b''
    for i in range(batch_size):
        r = random.random()
        if r < 0.70:
            ttype = 0  # STANDARD
        elif r < 0.90:
            ttype = 1  # BLOCK
        else:
            ttype = 2  # COMPLEX
        
        trade = Trade(
            trade_id=base_id + i,
            timestamp_ns=time.time_ns(),
            symbol_id=1000 + random.randint(0, 4999),
            price=1000000000 + random.randint(0, 100000000),
            quantity=100 * random.randint(1, 1000),
            buyer_order_id=(base_id + i) * 2,
            seller_order_id=(base_id + i) * 2 + 1,
            buyer_account=random.randint(0, 9999),
            seller_account=random.randint(0, 9999),
            trade_type=ttype,
            clearing_status=0,
            flags=0
        )
        trades += encode_trade(trade)
    return trades

def trade_load_generator(target_rate_tps: float, host: str, port: int, duration_sec: int):
    """Generate trade execution traffic at target rate."""
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect((host, port))
    
    batch_size = 16
    interval = batch_size / (target_rate_tps * 1e6)
    base_id = 0
    
    print(f"Generating {target_rate_tps} M trades/s to {host}:{port}")
    
    start = time.perf_counter()
    while time.perf_counter() - start < duration_sec:
        loop_start = time.perf_counter()
        batch = generate_trade_batch(batch_size, base_id)
        sock.sendall(batch)
        base_id += batch_size
        
        elapsed = time.perf_counter() - loop_start
        sleep_time = interval - elapsed
        if sleep_time > 0:
            time.sleep(sleep_time)
    
    sock.close()

if __name__ == '__main__':
    import sys
    rate = float(sys.argv[1]) if len(sys.argv) > 1 else 1.0  # 1M trades/s
    host = sys.argv[2] if len(sys.argv) > 2 else '127.0.0.1'
    port = int(sys.argv[3]) if len(sys.argv) > 3 else 8080
    duration = int(sys.argv[4]) if len(sys.argv) > 4 else 60
    trade_load_generator(rate, host, port, duration)
```

## Analysis

### Identifying Bottlenecks

| Symptom | Likely Cause | Remedy |
|---------|-------------|--------|
| Throughput plateaus at low core count | Position update contention | Shard positions by account |
| High clearing latency | Complex trade handling | Parallelize clearing, pre-validate |
| Reporting backlog under load | Network bottleneck | Batch reports, use multicast |
| Position update bottleneck | Cache coherence | Use per-core position shards |
| Settlement delays | External dependency | Async settlement, local pre-settlement |

### Optimization Checklist

- [ ] Position updates sharded by account (no cross-account locks)
- [ ] Trade reporting batched (16+ trades per report)
- [ ] Clearing pipeline parallelized across cores
- [ ] Trade encoding uses zero-copy where possible
- [ ] Settlement is asynchronous (don't block trade processing)
- [ ] NUMA-local position storage
- [ ] Cache-line alignment for trade structures
- [ ] Batch trade processing (16+ trades per iteration)
- [ ] Hardware timestamping on trade execution
- [ ] Pre-allocated trade ID pool (no dynamic allocation)
