# Synthetic benchmark examples

The historical `stac` directory name and `run_stac_*` function names are retained for compatibility. These are independently authored Python examples, not official STAC specifications or results. No licensed harness or premium workload is implemented here. STAC names remain their owners' trademarks.

The examples measure Python operations and their instrumentation. In-memory `send_order` and network models do not perform real NIC transmission. The risk example does not implement the official STAC-A2 workload. Cross-family ranking and the former overall STAC score are withdrawn.

Run examples with `python benchmarks/stac/run_all.py`. Result records identify unofficial synthetic authority. Use Apex_PerfAtlas for eligible metric-specific comparisons; authorized STAC execution belongs in a separately licensed private adapter.
